# Bundled mobile fonts

These fonts are licensed under the SIL Open Font License 1.1 and were built from the complete upstream font files, including their Vietnamese glyph coverage. The exact upstream notices are bundled beside the fonts as `Lora-OFL.txt` and `BeVietnamPro-OFL.txt`. The immutable Google Fonts source commit is `389b770410cc0b7c21c85673bfa2077420fe7f65`.

The WOFF2 files were generated with fontTools 4.57.0 and Brotli compression. Lora was instantiated at weight 600 from its variable source; the Be Vietnam Pro static sources were converted without subsetting.
